# Голос — телефонный backend (Twilio)

Этот сервис добавляет собственную VoIP-телефонию в приложение «Голос». Он не перехватывает аудио системного Phone, WhatsApp или Telegram. Пользователь совершает и принимает PSTN-звонки через номер и инфраструктуру Twilio внутри приложения.

## Что реализовано

- выдача короткоживущих Twilio Voice Access Tokens; ключи Twilio остаются только на сервере;
- приём аудио и AI-конвейер: русская/многоязычная транскрибация с разделением спикеров, таймкодами и AI-конспектом;
- библиотека AI-записей: поиск на iPhone, повторное открытие полного текста, скачивание и удаление;
- исходящий маршрут app → Twilio → обычный телефонный номер;
- входящий маршрут Twilio number → приложение golos-user (после настройки VoIP Push Credential);
- голосовое уведомление вызывающей и вызываемой стороны до соединения;
- серверная двухканальная запись разговора с момента ответа (record-from-answer-dual);
- проверка подписи webhook-запросов Twilio;
- список завершённых записей и защищённая загрузка MP3;
- ограничение исходящих направлений по E.164-префиксам; по умолчанию исходящие номера запрещены.

## Требования

- Node.js 22+;
- HTTPS URL с постоянным диском для DATA_DIR;
- аккаунт Twilio с Programmable Voice, номером и TwiML Application;
- для входящих звонков в фоне: Apple Developer account, VoIP Push entitlement/certificate и Push Credential SID в Twilio.

## Локальная проверка

```bash
cp .env.example .env
npm install
npm test
npm start
```

GET /health не требует авторизации. Остальные app API требуют Authorization: Bearer <GOLOS_APP_API_TOKEN>. Установите длинный случайный GOLOS_APP_API_TOKEN на сервере и в защищённых настройках приложения. Не используйте один и тот же токен в нескольких клиентах.

## Настройка Twilio

1. В Twilio Console создайте API Key и Secret; Account SID и Auth Token берутся из аккаунта.
2. Купите или подключите телефонный номер, доступный для голосовой связи. Присвойте его TWILIO_CALLER_ID.
3. Создайте TwiML Application. Её Voice URL: https://ВАШ-ДОМЕН/v1/voice/twiml, метод POST. SID запишите в TWILIO_APP_SID.
4. В настройках номера поставьте Voice webhook https://ВАШ-ДОМЕН/v1/voice/incoming, метод POST.
5. На Render `PUBLIC_BASE_URL` автоматически определяется по `RENDER_EXTERNAL_HOSTNAME`; на другом хостинге задайте его вручную как точный HTTPS origin backend без завершающего /.
6. Установите ALLOWED_DIAL_PREFIXES, например +31. Пустое значение блокирует все исходящие направления.
7. Установите TWILIO_PUSH_CREDENTIAL_SID после настройки VoIP push. Без него исходящие звонки работают, но входящие push-вызовы не будут доставляться приложению.
8. Разверните backend с постоянным диском, чтобы данные телефонных записей и каталог `ai-recordings/` сохранялись между перезапусками. Для Render в репозитории есть Blueprint `render.yaml`; создайте сервис вручную через Render Blueprint и заполните запрашиваемые секреты.

Twilio должен вызывать webhook по публичному HTTPS URL; сервер проверяет X-Twilio-Signature. Если домен, путь, query string или proxy URL расходятся с фактическим публичным URL, проверка подписи отклонит запрос.

## Запись и уведомление участников

Запись выполняется на стороне телефонного провайдера, а не микрофоном iPhone. Для исходящего звонка пользователь приложения подтверждает запись переключателем, а вызываемый абонент нажимает 1 в голосовом меню /v1/voice/whisper. Для входящего PSTN-звонка звонящий нажимает 1 в /v1/voice/incoming до соединения с приложением. События подтверждения сохраняются в recording-consents.jsonl. Это техническая фиксация выбора, а не юридическое заключение: проверьте применимое законодательство, дополнительные требования к согласию и идентификации участников.

## AI-обработка аудиозаписей

На сервере задайте `OPENAI_API_KEY`. Ключ хранится только в переменных окружения backend и никогда не передаётся в iOS-клиент. Модель по умолчанию — `gpt-4o-transcribe-diarize` для сегментов, таймкодов и спикеров; для длинных файлов включается `chunking_strategy=auto`. Важно: OpenAI объявила эту модель устаревающей с отключением 26 февраля 2027 года. До этой даты она используется ради diarization. Для перехода на текущую `gpt-transcribe` достаточно поменять `OPENAI_TRANSCRIPTION_MODEL`; backend автоматически переключится на формат JSON, но метки спикеров исчезнут. Для сохранения diarization после отключения потребуется отдельный сервис распознавания спикеров. `gpt-6-luna` используется для структурированного конспекта. Модели можно переопределить через `OPENAI_TRANSCRIPTION_MODEL` и `OPENAI_SUMMARY_MODEL`.

Форматы загрузки: MP3, MP4, MPEG, MPGA, M4A, WAV и WEBM. Максимальный размер одного файла — 23 МиБ. Длинные записи, превышающие лимит, необходимо разделить на части перед загрузкой. Исходное аудио и результаты хранятся в `DATA_DIR/ai-recordings` на сервере; для сохранности после redeploy обязателен постоянный диск. Автоматического срока удаления пока нет: ненужные материалы необходимо удалить из библиотеки приложения. Удаление удаляет и серверную копию.

- `POST /v1/ai/recordings` — отправка сырого аудиофайла; заголовки `Content-Type`, `X-File-Name` и `Authorization: Bearer ...` обязательны. Ответ содержит текст, сегменты, summary и задачи.
- `GET /v1/ai/recordings?q=текст` — библиотека и полнотекстовый поиск по названию, конспекту и полной расшифровке.
- `GET /v1/ai/recordings/:id` — полная расшифровка и конспект.
- `GET /v1/ai/recordings/:id/audio` — оригинальный аудиофайл.
- `DELETE /v1/ai/recordings/:id` — удаление записи и аудио.

Если транскрибация успешна, но модель конспекта недоступна, запись сохраняется с полной расшифровкой и предупреждением; конспект в таком случае не появляется. В текущей версии AI-обработка запускается из приложения для записи с микрофона, импортированного аудио и скачанной MP3-записи звонка.

## API

- GET /health
- POST /v1/voice/token — JSON { "identity": "golos-user" }, ответ { accessToken, identity, expiresIn }.
- GET /v1/voice/recordings — список завершённых записей.
- GET /v1/voice/recordings/:recordingSid/audio — защищённая загрузка MP3.
- Twilio webhooks: POST /v1/voice/twiml, /v1/voice/incoming, /v1/voice/incoming-consent, /v1/voice/whisper, /v1/voice/recording-consent, /v1/voice/recording-events.

## Ограничения текущего этапа

- Это отдельная телефония внутри приложения, не маршрутизация обычного SIM-вызова с iPhone.
- Звонки WhatsApp/Telegram/FaceTime не записываются и не перенаправляются.
- Входящие VoIP push требуют реальной настройки APNs и Twilio Push Credential, а также физического iPhone и подписанного приложения.
- Аудиофайлы телефонных звонков исходно хранятся у Twilio; после скачивания в приложении их можно отправить в AI-конвейер, где копия хранится на постоянном диске backend.
- GOLOS_APP_API_TOKEN — временная схема персонального MVP. Перед многопользовательским распространением её нужно заменить полноценной пользовательской авторизацией.
