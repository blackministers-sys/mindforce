# Голос — телефонный backend (Twilio)

Этот сервис добавляет собственную VoIP-телефонию в приложение «Голос». Он не перехватывает аудио системного Phone, WhatsApp или Telegram. Пользователь совершает и принимает PSTN-звонки через номер и инфраструктуру Twilio внутри приложения.

## Что реализовано

- выдача короткоживущих Twilio Voice Access Tokens; ключи Twilio остаются только на сервере;
- исходящий маршрут app → Twilio → обычный телефонный номер;
- входящий маршрут Twilio number → приложение golos-user (после настройки VoIP Push Credential);
- голосовое уведомление вызывающей и вызываемой стороны до соединения;
- серверная двухканальная запись разговора с момента ответа (record-from-answer-dual);
- проверка подписи webhook-запросов Twilio;
- список завершённых записей и защищённая загрузка MP3;
- ограничение исходящих направлений по E.164-префиксам; по умолчанию исходящие номера запрещены.

## Требования

- Node.js 22+;
- HTTPS URL с постоянным диском для DATA_DIR;
- аккаунт Twilio с Programmable Voice, номером и TwiML Application;
- для входящих звонков в фоне: Apple Developer account, VoIP Push entitlement/certificate и Push Credential SID в Twilio.

## Локальная проверка

```bash
cp .env.example .env
npm install
npm test
npm start
```

GET /health не требует авторизации. Остальные app API требуют Authorization: Bearer <GOLOS_APP_API_TOKEN>. Установите длинный случайный GOLOS_APP_API_TOKEN на сервере и в защищённых настройках приложения. Не используйте один и тот же токен в нескольких клиентах.

## Настройка Twilio

1. В Twilio Console создайте API Key и Secret; Account SID и Auth Token берутся из аккаунта.
2. Купите или подключите телефонный номер, доступный для голосовой связи. Присвойте его TWILIO_CALLER_ID.
3. Создайте TwiML Application. Её Voice URL: https://ВАШ-ДОМЕН/v1/voice/twiml, метод POST. SID запишите в TWILIO_APP_SID.
4. В настройках номера поставьте Voice webhook https://ВАШ-ДОМЕН/v1/voice/incoming, метод POST.
5. Установите PUBLIC_BASE_URL в точности равным HTTPS origin backend без завершающего /.
6. Установите ALLOWED_DIAL_PREFIXES, например +31. Пустое значение блокирует все исходящие направления.
7. Установите TWILIO_PUSH_CREDENTIAL_SID после настройки VoIP push. Без него исходящие звонки работают, но входящие push-вызовы не будут доставляться приложению.
8. Разверните backend с постоянным диском, чтобы data/recording-events.jsonl сохранялся между перезапусками.

Twilio должен вызывать webhook по публичному HTTPS URL; сервер проверяет X-Twilio-Signature. Если домен, путь, query string или proxy URL расходятся с фактическим публичным URL, проверка подписи отклонит запрос.

## Запись и уведомление участников

Запись выполняется на стороне телефонного провайдера, а не микрофоном iPhone. До соединения приложение проигрывает уведомление вызывающему, а endpoint /v1/voice/whisper — вызываемому участнику. Это техническое уведомление не заменяет проверку применимых правил записи разговоров и получение необходимого согласия. Пользователь обязан убедиться, что запись допустима и все участники уведомлены/согласны; при возражении разговор следует завершить.

## API

- GET /health
- POST /v1/voice/token — JSON { "identity": "golos-user" }, ответ { accessToken, identity, expiresIn }.
- GET /v1/voice/recordings — список завершённых записей.
- GET /v1/voice/recordings/:recordingSid/audio — защищённая загрузка MP3.
- Twilio webhooks: POST /v1/voice/twiml, /v1/voice/incoming, /v1/voice/whisper, /v1/voice/recording-events.

## Ограничения текущего этапа

- Это отдельная телефония внутри приложения, не маршрутизация обычного SIM-вызова с iPhone.
- Звонки WhatsApp/Telegram/FaceTime не записываются и не перенаправляются.
- Входящие VoIP push требуют реальной настройки APNs и Twilio Push Credential, а также физического iPhone и подписанного приложения.
- Аудиофайлы хранятся у Twilio; backend хранит метаданные и выдаёт защищённый поток MP3. Автоматическая транскрибация, разделение спикеров и AI-конспект ещё не подключены.
- GOLOS_APP_API_TOKEN — временная схема персонального MVP. Перед многопользовательским распространением её нужно заменить полноценной пользовательской авторизацией.
