# Голос — нативный iOS technical spike

Этот каталог — отдельный нативный iPhone-клиент, не затрагивающий PWA в `voice-note/` и основной MindForge.

## Что входит в первый прототип

- SwiftUI shell для iPhone.
- Запись встреч и личных заметок с микрофона по явному действию пользователя.
- Импорт готовых аудиофайлов из Files.
- Наблюдение за изменением состояния вызовов через CallKit (`CXCallObserver`) как технический эксперимент.

## Критическое ограничение платформы

CallKit предоставляет интерфейсы и состояние вызовов, но не аудиопоток стороннего телефонного или VoIP-разговора. AVAudioSession также не даёт приложению захватывать микрофон активного вызова, который обслуживает другое приложение. Поэтому этот прототип намеренно **не запускает скрытую запись при обнаружении чужого звонка** и не обещает записывать звонки Phone, WhatsApp, Telegram или FaceTime.

Официальные ссылки:
- [CallKit](https://developer.apple.com/documentation/callkit)
- [AVAudioSession](https://developer.apple.com/documentation/avfaudio/avaudiosession)
- [Apple Support: запись звонков и региональная доступность](https://support.apple.com/en-ie/guide/iphone/iph57c6590e9/27/ios/27)

На дату исследования Apple указывает, что встроенная запись звонков недоступна в ЕС и России. Доступность зависит от региона и версии iOS.

## Сборка

Откройте `Golos.xcodeproj` в Xcode и запустите схему `Golos` на iPhone Simulator или подключённом iPhone. Для установки на физическое устройство потребуется подпись приложения собственным Apple Developer Team.

## Следующий технический тест

1. Установить приложение на iPhone.
2. Проверить, какие вызовы реально отражаются в `CXCallObserver` (обычная связь, FaceTime, WhatsApp, Telegram).
3. Отдельно подтвердить, что приложение не получает удалённый звук разговора.
4. На основании результатов выбрать допустимые сценарии: импорт системной записи, собственный VoIP-звонок с записью на сервере, либо внешний источник записи с последующим импортом.

Никаких обещаний автоматической записи чужих звонков до прохождения этих тестов нет.
