# Голос — нативный iOS-клиент

Ветка содержит нативное приложение iPhone и собственный телефонный backend. PWA в `voice-note/` и основная ветка `main` не меняются.

## Реализовано в коде

- SwiftUI-клиент iPhone.
- Запись встреч и заметок через микрофон, импорт аудиофайлов.
- Диагностическое наблюдение за системными вызовами через CallKit без доступа к аудио этих вызовов.
- Twilio Voice SDK 6.13.8: исходящие звонки через собственную телефонию.
- PushKit и CallKit каркас для приёма входящих звонков.
- Хранение URL backend и персонального API-токена в iOS Keychain.
- Сервер выдаёт короткоживущие Voice Access Tokens, проверяет подписи webhook-запросов, маршрутизирует звонки, обрабатывает согласие на запись, получает dual-channel recording events и выдаёт MP3 через защищённый endpoint.

## Ограничения

Приложение не перехватывает звонки SIM в Apple's Phone, WhatsApp, Telegram, FaceTime или других приложениях. Звонок должен проходить через номер/маршрут Twilio внутри «Голоса». Simulator CI не заменяет проверку физического iPhone, APNs и подписанного приложения.

## Что необходимо для реального звонка

1. Развернуть `voice-backend` на публичном HTTPS-хосте с постоянным диском.
2. Настроить Twilio Account SID, Auth Token, API Key SID/Secret, TwiML Application SID, Caller ID и разрешённые направления вызовов.
3. Настроить Twilio Voice Push Credential и Apple APNs для входящих вызовов.
4. Установить персональный `GOLOS_APP_API_TOKEN` в переменные backend и в защищённые настройки приложения.
5. Подписать приложение через Apple Developer Team и проверить входящие/исходящие вызовы на физическом iPhone.

## Запись и согласие

Для исходящего звонка пользователь подтверждает уведомление переключателем, а вызываемый абонент нажимает 1 в голосовом меню. Для входящего PSTN-вызова звонящий нажимает 1 до соединения; входящий экран CallKit обозначает вызов как записываемый. События согласия сохраняются в `recording-consents.jsonl`. Это техническая фиксация, а не юридическое заключение: проверьте применимые правила и дополнительные требования к согласию. Если участник не согласен, вызов не соединяется.
