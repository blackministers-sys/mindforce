# Голос — умный диктофон (MVP)

Мобильное PWA-приложение для самостоятельной записи аудио через микрофон телефона и ведения текстовых заметок.

## Уже реализовано
- Запись с микрофона через MediaRecorder API.
- Пауза, продолжение и завершение записи.
- Импорт аудиофайлов из файлового хранилища телефона (до 250 МБ на файл).
- Сохранение аудио и заметок в IndexedDB на устройстве.
- Библиотека, поиск, фильтры, переименование и удаление.
- Прослушивание и скачивание аудиофайлов.
- PWA-манифест и Service Worker для установки/кэширования интерфейса.

## Ограничения текущего MVP
- Это локальный прототип: записи хранятся в браузере на конкретном устройстве и пока не синхронизируются между телефоном и компьютером.
- Запись в iOS Safari должна оставаться в открытом приложении. Браузер может остановить запись при блокировке экрана, уходе в фон или закрытии вкладки.
- Транскрибация, определение говорящих и AI-конспекты пока не подключены. Распознавание — следующий этап. Для них нужен защищённый серверный API и ключ провайдера; ключ нельзя помещать в клиентский JavaScript.
- Вызовы системных телефонных звонков не записываются. Приложение использует только доступный ему микрофон.

## Запуск локально
Откройте папку через HTTPS-хостинг или локальный сервер:
```bash
python -m http.server 8080
```
Затем откройте `http://localhost:8080/voice-note/` в браузере. Для доступа к микрофону на реальном устройстве требуется HTTPS.

## Установка на iPhone

1. Откройте опубликованный HTTPS-адрес в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» и подтвердите добавление.
4. Запускайте приложение с новой иконки. Для первой записи разрешите доступ к микрофону.

## Следующие этапы
1. Проверить запись, импорт, воспроизведение и хранение на физическом iPhone в Safari, включая длинные файлы и перезапуск приложения.
2. Исследовать локальную русскую транскрибацию в браузере; не обещать офлайн-режим до успешного теста.
3. Серверная транскрибация аудио и AI-обработка: краткое содержание, решения, задачи, вопросы и ключевые цитаты.
4. Авторизация и синхронизация между iPhone и компьютером через Supabase.
5. Разделение по проектам/категориям, теги и экспорт конспектов.
6. Проверка iOS Safari, установка на экран «Домой», тестирование длинных записей и восстановления после прерываний.

## Архитектура
- Frontend: HTML/CSS/JavaScript, PWA.
- Локальная очередь и метаданные: IndexedDB.
- Дальнейшее облачное хранение/синхронизация: Supabase (планируемый этап).
- AI: серверная интеграция с выбранным провайдером; секреты только на backend.
